# 工厂标准色（首批）

## 来源与口径

首批标准色以【下单小程序】中已提交的横款、竖款袋子实拍为证据，图片名称和小程序结构化的 `bagColor / handleColor` 共同确认布料颜色。当前证据包括：

- 竖版常规颜色实拍 21 张；
- 竖版服装店颜色实拍 24 张；
- 横款颜色参考图 16 张，其中常规色 8 张、服装店色 8 张。

`咖米提、焦糖米提、白黑提、粉袋酒红提` 等名称描述的是“袋身颜色＋提手颜色”的成品组合，不是一个新的布料颜色。ERP 必须将组合拆成袋身和提手两个标准色，不能把组合名写入卷料标准色。

## 首批 35 个标准色

| 色系 | 标准色 |
| --- | --- |
| 红/粉/紫 | 红色、玫红、珊瑚粉、粉色、安哥拉红、酒红、冰梅、紫色、香芋紫、芋泥紫 |
| 黄/棕/中性色 | 黄色、小鸡黄、酱黄、橘色、焦糖、咖色、卡其、白色、米白、灰色、黑色 |
| 蓝色 | 宝蓝、天蓝、海蓝、牛仔蓝、湖蓝、雾霾蓝 |
| 绿色 | 墨绿、亮绿、果绿、草绿、抹茶绿、橄榄绿、荧光绿、豆绿 |

标准色在代码中的唯一清单和色块值位于 `shared/factoryStandardColors.js`，数据库由 `0046_factory_standard_colors.sql` 幂等写入同一批名称。

## 兼容与新增规则

- 历史明确同义词按兼容别名处理：`本白 → 白色`、`大红 → 红色`、`宝兰 → 宝蓝`、`天兰 → 天蓝`、`桔红 → 橘色`。
- 工厂已明确确认不存在 `云雅绿、天池蓝、梦幻紫` 这三个颜色；它们不得进入厂内标准色、普通候选色或自动映射结果。
- 不同厂家票面叫法不能靠相似字或相似色静默合并。ERP 保留票面原文，并通过有审计的“供应商＋票面颜色 → 厂内标准色”规则自动换算。
- 后续新颜色需要有实物色卡/照片和有权限的主数据维护记录；一次 OCR 人工修正不能静默扩充标准色或改写映射。
