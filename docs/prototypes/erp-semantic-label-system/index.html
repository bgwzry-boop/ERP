Component contract

组件不接受随意颜色，只接受业务语义

选择类别和值，得到稳定标签和可复制的 React 调用。未知值统一回落为“待确认”，不会猜测颜色。

Density scale

只改变尺寸，不改变语义

不同端共享同一映射；密度由容器选择，不由业务页面重新配色。
