## 修复内容

1. 标准通货首批完工没有库存档案时，按订单规格及已有唯一标准色原子建立库存。客户订单同时占用，补库只增库存；特殊尺寸及丝印中间工序不建立通货库存。幂等、并发、四类库存数量及回滚均经真实数据库验证。
2. 固定签名测试身份增加手机现场流程入口，仍受原权限及服务器规则约束，生产环境和普通账号不开放该测试入口。手机首批报工移除错误的本地库存前置阻断，签名请求不得降级为本地成功。
3. 手机报工/打包缺少本地客户缓存时不崩溃，也不借用缓存中的第一位客户；按客户编号核对后显示服务器提供的客户名。
4. 已提供但过期/无效的身份凭证明确返回401，固定测试身份可安全重新验证。同身份续签保留订单、收货、逐包数量及排产输入和未知回执原请求；不自动重发业务写入。撤销、停用、换人及撤权仍隔离。
