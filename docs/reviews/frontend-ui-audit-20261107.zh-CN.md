# ERP 代码与界面审查记录（2026-11-07）

本文件记录本轮审查范围和证据口径，不代替服务器发布身份。当前部署版本必须通过 `npm run release:check` 核对；本地 4174 始终是“本地修改稿 · 未部署”。生产服务器不在本轮授权范围。

## 基线与修复范围

审查从当时 canonical `3fe8c97fc25b6c1c5e2623e1191af27e382a3a51` 开始。所有修改在独立分支中评审，集成候选由专门任务组装；不得先推进 canonical 再部署。

| 范围 | 本轮核对与处理 |
|---|---|
| 订单识别（#67） | 单条、批量及保存时的明细编号按草稿隔离；保留已保存编号，不把重复写入包装为成功 |
| 授权（#68） | 单数/复数岗位字段同等检查；临时密码等入口核对操作人权限；公网不接受伪装成本机的免签身份；测试评审继续交换固定签名身份 |
| 多色报价（#69） | 油墨集合顺序不改变合组；相关入口支持同一色数上限，不静默截成四色 |
| 确认订单（#70） | 只能确认已经保存的业务字段；空字段不能在确认请求中绕过保存和重报价；日期按业务精度归一比较 |
| 库存（#71、#81） | 统一扣除占用、锁定与待处理；允许登记真实盘亏差异并留证；确认或驳回须有版本、权限和幂等保护。旧 #75/#80 不纳入 |
| 会话/附件（#72、#73） | 改密使旧会话失效；附件密钥空值不再成为可猜测固定密钥 |
| 基础界面（#74、#76、#77、#78、#79） | 单一主内容区域；错误编号可追日志；未知地址与内容一致；区分未接数据源与无记录；收货脏状态按实例隔离 |
| 录单交互（#82） | 菜单、搜索、地址与新建共用提示占用；保留取消前的原文/客户/行；拆单和待核对回执不能被绕过；接受只提交一次固定目标；身份就绪后再处理冷启动深链 |
| 电脑库存/财务（#84） | 重置不竖排；共享横滚且保留长表表头；库存四项完整可见；“本期未收”直接读取 `currentUnpaid`，缺失不是零，不拿历史差额替代 |
| 手机交互（#86） | 收货按钮触控与布局、退出弹窗焦点/等待保护、库房遮罩拦截背景操作；独立终审结果以发布证据为准 |

## 手机覆盖与边界

使用真实手机UA、390×844、`isMobile`、`hasTouch`，直接挂载真实业务组件/CSS，数据为隔离夹具，所有业务写请求阻断。8类岗位均完成主页、主要表单/确认和取消的组件级测试：

- 办公室收货；成品库房；司机；制袋；丝印；打包；机修；经营决策。
- 管理、财务和技术岗位在手机提示转电脑属于当前既定边界。
- 修复另核对375/390/430/500宽度、实际按钮点击位置、44px触控区、颜色12/14字号、常见规格/重量及弹窗保护。

这不证明真实岗位权限、全厂账号开通、摄像头/高拍仪、扫码枪、打印机或现场业务闭环通过。正式账号注册、授权、工资试点范围继续服从当前业务基线。

## 已验证专项与持续检查

- 13项代码修复的组合版本经过订单、报价、小程序、权限、会话、附件、库存差异及并发PostgreSQL检查；记录保留固定来源，不以单个PR绿灯代替组合验证。
- 录单独立16项覆盖原文、客户/行保留、取消/接受、搜索、新建、刷新、拆单、丢回执原键重试与连续导航；冷启动另测管理专属页、最终无权及未知地址。
- 库存长表使用确定性两类各30行夹具：在库10000、占用2345、锁定3456、待处理1234，可用2965。逐项检查精确值、六列、真实纵滚、首末行、全部裁切祖先和视口。已知表头回归版本也必须测试失败。
- 手机退出弹窗必须默认聚焦“继续核对”；仅在真实作废请求等待时阻断关闭。无作废权限不能阻止继续核对；失败回执后仍保留草稿。遮罩打开时底栏不能操作背景。
- CI和本地 `review:check` 保留原有检查，并执行新增录单、身份深链、路由组合、库存几何及手机回归。新增测试不得静默跳过缺行/缺列，或依赖碰巧有业务数据。

## 发布与未覆盖范围

仅在最终候选代码、界面、组合检查与CI通过后，使用准确40位提交和同一受控锁执行 `controlled-release:deploy`。服务器前端/API验明后才由finalize推进canonical和干净主目录。备份、原业务列指纹、回滚点与环境哈希必须保留。

本轮不把以下工作写成已完成：完整逐操作业务UAT、实物打印对位、真实相机扫码设备、正式支付/付款、全厂考勤工资与实际送货现场验收。每次交付仍应列出真实目标、版本身份、检查结果和这些边界。
