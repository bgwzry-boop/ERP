## 复现与修复

| 问题与后果 | 修正 |
| --- | --- |
| 原生打印同步关闭预览时，先调用 print 再监听 afterprint，错过关闭事件，结果确认可能要等两分钟 | 在调用打印前注册事件；关闭、抛错和兜底只结束一次，并清理监听与计时器。打印结果仍需人工确认 |
| 上月无单号同金额同重量退货抢配本月 Excel 行，本月真实退货又追加一条调整；-100 变成 -200 | 匹配前筛选本期退货；无明确身份的日期矛盾不模糊匹配，已有来源归属和供应商不能被覆盖，保留原 Excel 事实 |
| 排产请求自行携带“已完成／已交付”等状态，未经报工或出库就可写入终态 | 排产状态由既有服务端工序规则推导；矛盾字段返回冲突，不产生业务写入或审计／决定副作用，兼容合法同值请求 |
| 领料机台解析允许不存在的第5–9台丝印机 | 按现有4台丝印、9台制袋常量校验，保留旧别名及丝印车间入口，未知机台不能领料 |
| 已有供应商付款规则允许实付加抹零结清，但命令层漏传抹零字段，应付10850、实付10800、抹零50仍显示欠50 | 命令转发抹零到已有付款确认校验；不新增财务规则，超额、负数、非结清抹零及重复付款继续受原校验限制 |
