继续核对时追加修复

  • 派车对象资格：服务端拒绝停用、禁止登录、非司机或离职人员；数据库提交时再次核对。
  • 盘点重复确认与凭证：无有效凭证不能确认；旧盘点不能覆盖新库存；锁等待期间数量、归属或凭证变化会中止整个事务。
  • 原料金额与原始汇总：金额使用金额规则核对，零额或差额不能借重量容差放行；排除误识别行保留票面原汇总并要求处理差异。
  • 卷码与厂家码碰撞：正式卷码优先精确匹配；厂家码歧义明确阻断，避免扫码选错实物卷。
  • 已结账期被重新打开：收款和沟通不得绕过已结账期保护，追加沟通不改变已核销等财务终态。
  • 多张收款凭证与付款记录身份：完整保留全部有效凭证关联，付款记录唯一且不可覆盖；同一提交重试不重记。
  • 分批纸单金额：按本次交付的正式计费依据分摊，以分为单位处理尾差；已入账交付沿用该次已入账金额，历史打印快照保留。
  • 导出对账文件不得改账：导出只保存不可变文件与审计快照，不能删改正式对账明细；账目在导出期间变化时拒绝生成含糊证据。
  • 真实数据库打印回执字段超限：拆分数据库回执构造并保留全部字段，避免正常打印交易因字段数量超限失败。
  • 计划数量冒充已出库与估算金额：电脑页以服务器全部同单实物出库记录汇总；未出库计划不减少剩余未实出。取消无依据的应收和欠款估算，转到正式对账核对。
