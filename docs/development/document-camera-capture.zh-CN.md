# 高拍仪 / 标准摄像头拍照

办公室把厂家送货单或凭证放在高拍仪下时，网页直接打开预览、拍一张，并把这张 JPEG 交给当前单据原来的附件处理，不再先在厂商软件里存盘、再手动选文件上传。

## 浏览器怎么接

- 使用 `navigator.mediaDevices.getUserMedia` 打开画面，使用 `enumerateDevices` 列出视频输入。
- 多台摄像头时可以选择设备。高拍仪如果被系统认成普通摄像头，列表里会显示它的设备名。
- 拍下的文件走原来的送货单识别、凭据、工资调整、盘点凭证或对账单上传函数。
- `从相册 / 文件选择` 保留。权限被拒绝、没有摄像头、摄像头被占用时，页面用中文说明，并继续允许文件上传。

## 网页枚举不到时

本实现不调用未知厂商的私有 SDK。如果高拍仪只在自己的拍摄软件里出现，浏览器设备列表里没有它，网页就无法拍照。处理方式：

1. 在高拍仪或其驱动里打开 UVC / Webcam 模式，让操作系统把它识别为标准摄像头。
2. 确认浏览器地址栏已允许使用摄像头，并关闭正在独占设备的厂商软件。
3. 若该型号不能切换到标准摄像头，改用能被系统识别为摄像头的型号，或继续用文件上传。
