# 生产看板快速审查

## Step 1 - 1440x1024 默认生产看板

Health: 可用，但调度决策层级还不够清楚。

Strengths:
- 主结构正确：深色模块导航、顶部 API 同步、KPI、合批建议、双车间短队列、机台详情都在同一屏。
- 4 台丝印机和 9 台制袋机的“小碎单短队列”方向比长甘特图更贴近业务。
- 线上/线下、定制印刷、换版清洗、余料复用这些关键业务词已经出现。

UX / design issues:
- KPI 区域过高，抢了生产队列的首屏空间。调度员最需要看队列和瓶颈，KPI 应该更像一条紧凑状态栏。
- 左侧合批建议一直展开，占据横向空间，导致机台任务卡过窄、文字很小。建议改成可折叠面板或只在“待合批”模式展开。
- 任务卡信息太多：订单号、规格、颜色、数量、分钟都挤在 30px 高度里，真实使用时会扫不清。建议卡片只保留订单号、数量、时长、风险色，规格/颜色进悬浮或右侧详情。
- “当前瓶颈 S2”在 KPI 里很醒目，但主看板里的 S2 没有足够强的行级强调。调度员应一眼看到瓶颈行和可插单窗口。
- 右侧详情和主队列连接还弱：选中任务有蓝框，但右侧详情没有明确显示“为什么这个任务被选中 / 下一步该做什么”。

Accessibility risks:
- 多处小字接近 9-10px，长期使用和普通显示器上会吃力。
- 部分浅绿卡片里的文字对比偏低，生产现场屏幕或较差显示器上可读性风险较高。
- 图标按钮依赖图形理解，后续需要 tooltip 或可访问标签。

## Step 2 - 1280x900 窄桌面状态

Health: 主内容未破版，但信息优先级更明显暴露。

Strengths:
- 右侧详情被隐藏后，主看板没有横向裁切，布局稳定。
- 合批建议和机台队列仍然能同时看到，适合小屏办公室电脑。

UX / design issues:
- 右侧详情隐藏后，调度动作入口也消失了；用户选中任务后没有明显的“调整顺序 / 插单 / 完工登记”操作区。
- KPI 变成两行大卡片，进一步压缩队列高度。窄屏下应改为一行横向滚动或更紧凑的指标条。
- B6 以后需要滚动才能看到，制袋车间 9 台机的整体负载对比不够完整。窄屏下可以增加一个“制袋机负载总览小条”。

Recommended changes:
1. 把顶部 6 个 KPI 改为紧凑状态条，减少首屏高度。
2. 把左侧合批建议改成可折叠，默认显示 3 条高价值建议。
3. 任务卡减字：只保留 `订单号 + 数量 + 分钟 + 风险色`，规格/颜色放到详情。
4. 给 S2 瓶颈行增加整行强调和“处理建议”：转派、拆批、插单窗口。
5. 在 1280 宽时增加底部浮动操作条，避免右侧详情隐藏后无法操作。
6. 放大关键小字到至少 11-12px，提高现场可读性。
